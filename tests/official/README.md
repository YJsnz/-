# 官方样例（tests/official）

本目录保存《2026年编译原理实验指导书》四个实验的官方样例，作为各阶段验收的最终标准。

## 目录与来源

| 目录 | 指导书位置 | 输入 | 期望输出 |
|---|---|---|---|
| `exp1/` | 实验一，第 2–4 页 | `testfile.txt` | `output.txt`（词法单元表） |
| `exp2/` | 实验二，第 5–9 页 | `testfile.txt`（与 exp1 相同） | `output.txt`（单词 + `<成分名>`） |
| `exp3/` | 实验三，第 12 页 | `testfile.txt` | `error.txt`（`2 a` / `6 k`） |
| `exp4/` | 实验四，第 13 页 | `testfile.txt` + `stdin.txt` | `pcoderesult.txt`（`Hello World` / `1837`） |

## 转录说明

- PDF 文字层存在字体映射错误（例如“错误”被抽成“文误”），本目录内容已按 PDF 页面渲染逐页核对。
- 实验一与实验二的样例输入完全相同，因此 `exp1/testfile.txt` 与 `exp2/testfile.txt` 内容一致，可用 `diff` 验证。
- 实验二输出 = 实验一输出 + 各语法成分结束处的 `<成分名>` 行。去掉所有 `<...>` 行后，应与 `exp1/output.txt` 完全一致。
- 样例中的缩进统一为 4 个空格；缩进不属于单词，不影响期望输出，但**行号**必须保持一致（实验三依赖行号）。
- 所有文件为 UTF-8（无 BOM）、LF 换行。

## 使用方式

- 阶段验收时，将对应实验的 `testfile.txt` 作为输入，逐字节比对输出文件。
- 实验三只比 `error.txt`，实验四只比 `pcoderesult.txt`。
- 从 P1-10 起，会把官方样例接入 `scripts/verify.sh`（通过 `tests/cases/` 中的用例目录），确保每次回归都覆盖。

## 约束

- **禁止修改本目录中的期望输出以让测试通过**；如指导书版本变化，需单独提交并说明来源页码。
